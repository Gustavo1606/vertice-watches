
# Vértice Watches

Projeto de e-commerce de relógios desenvolvido para o Challenge do 4º bimestre do Senac.

## Sobre o projeto

A Vértice Watches é uma loja virtual de relógios masculinos, femininos, digitais e smartwatches.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
- MySQL
- PDO

## Funcionalidades

- [x] Vitrine de produtos com imagens.
- [x] Filtro por categorias.
- [x] Cadastro e login de usuários.
- [x] Carrinho de compras.
- [x] Finalização de pedidos.
- [x] Simulação de pagamento.
- [x] Controle de estoque.
- [x] Painel administrativo.
- [x] Cadastro, edição e desativação de produtos.
- [x] Validação de formulários com JavaScript.

## Objetivo

Desenvolver uma loja virtual simples e funcional, aplicando os conhecimentos adquiridos durante as aulas de Tecnologia da Informação.

## Como executar o projeto

1. Instale o XAMPP.
2. Coloque a pasta do projeto dentro de htdocs.
3. Inicie o Apache e o MySQL.
4. Acesse o phpMyAdmin.
5. Crie o banco de dados vertice_novo.
6. Importe o arquivo vertice_novo.sql.
7. Copie config/config.example.php e renomeie a cópia para config.php, dentro da pasta config.
8. Acesse http://localhost/vertice_novo/ no navegador.

## Acesso administrativo

Cadastre uma conta pela loja e altere o tipo do usuário para admin no phpMyAdmin.

Após realizar o login, acesse:
http://localhost/vertice_novo/admin/
